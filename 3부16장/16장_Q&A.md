### Q1) 일반 flow {} 빌더와 channelFlow {} 빌더의 내부 동작 차이는 무엇인가요? 왜 channelFlow가 더 무겁다고 할까요?

**A) 김규**

- channelFlow는 여러 코루틴에서 값의 발행을 허용
- 채널 플로우는 여러 채널 관리가 별도로 필요해서 추가 비용이 있음
  - 생산자와 소비자의 속도가 달라도 동작할 수 있게끔 별도의 큐를 두고 있음
  - 여러 코루틴에서 동시다발적으로 값을 보내야 해서 동시성 문제를 해결하기 위해 락을 잡을 수도 있음
